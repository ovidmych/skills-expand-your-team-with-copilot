# Mergington High School Activities

A super simple website application that allows students to view and sign up for extracurricular activities.

## Features

- View all available extracurricular activities
- Sign up for activities

## Development Guide

For detailed setup and development instructions, please refer to our [Development Guide](../docs/how-to-develop.md).

## Requesting Changes

Teachers and administrators can request changes or report issues using our structured issue templates. These templates make it easy to submit requests without needing technical knowledge:

- **Add New Activity** - Request a new extracurricular activity
- **Modify Activity Details** - Change schedule, description, or capacity
- **Bug Report** - Report something that isn't working
- **Feature Request** - Suggest new capabilities
- **UI/UX Improvement** - Request interface improvements
- **Data Management** - Manage student enrollments

[Learn more about using issue templates](../docs/issue-templates-guide.md) | [Create a new issue](../../issues/new/choose)
